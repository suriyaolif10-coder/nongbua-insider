# พัฒนากรออกเควส

เกม RPG มุมมองจากด้านบน สำหรับ**พัฒนากร** ใช้ลงพื้นที่ติดตามหนี้กองทุนพัฒนาบทบาทสตรี (ทดสอบกับข้อมูล อ.โนนสัง และใช้กับอำเภออื่นได้)
ข้อมูลอ่านจากชีต "สถานะลูกหนี้ตามสัญญา รวม" (ชีต `ปี 60` … `ปี 67`) โดยตรง

- `index.html` คือตัวเกม (ถ้าเปิดนอก Apps Script จะเป็นโหมดทดลองที่ใช้ข้อมูลสมมติ)
- `Code.gs` คือตัวเชื่อม Google Sheet

## แผนที่อ่านข้อมูลอย่างไร
| ในชีต | ในเกม |
|---|---|
| แต่ละแถว (1 สัญญา/กลุ่ม) | บ้าน 1 หลัง มีชื่อโครงการ หมู่ และปีงบเขียนใต้บ้าน |
| ตำบลใน "สถานที่ดำเนินการ" | หมู่บ้านกลุ่มหนึ่งบนแผนที่ มีป้ายตำบลอยู่ตรงกลาง |
| สถานะการชำระหนี้ | สีของเครื่องหมายบนหลังคา และความด่วนของเควส |

| สถานะ | สี | ลำดับความด่วน |
|---|---|---|
| ทวงถามครั้งที่ 2 | แดง ! | 1 |
| ทวงถามครั้งที่ 1 | ส้ม ! | 2 |
| ค้างชำระ | เหลืองเข้ม ! | 3 |
| ปรับโครงสร้าง ตามประกาศรอบที่ … | ม่วง ! | 4 |
| รอชำระ | ฟ้า ! | 5 |
| ชำระครบตามสัญญา | เขียว ★ (ไม่เป็นเควส) | – |

บ้านที่เยี่ยมแล้วในเดือนนี้จะเปลี่ยนเป็น ✓ และจะกลับมาเป็นเควสใหม่ในเดือนถัดไป

## ดูข้อมูลแต่ละกลุ่ม
- **ซูมด้วยนิ้ว:** ใช้สองนิ้วถ่างเพื่อขยาย และหุบเพื่อย่อ (ปุ่ม + / − ก็ใช้ได้)
- **ป้ายปีที่กู้:** บ้านทุกหลังมีป้ายสี เช่น "ปี61" แต่ละปีงบใช้สีต่างกัน ดูคู่สีได้ในตาราง "แยกตามปีงบประมาณ" ในหน้าสรุป
- **แตะที่บ้าน:** ขึ้นข้อมูลย่อ บอกว่ากู้ปีงบไหน สถานะหนี้ เงินกู้ และเลขสัญญา กด "ดูทั้งหมด" เพื่อเปิดข้อมูลเต็มและบันทึกผล
- **ปุ่ม "สรุป":** ภาพรวมทั้งอำเภอ ได้แก่ จำนวนสัญญา เงินกู้รวม จำนวนที่ค้างหรือถูกทวงถาม จำนวนที่เยี่ยมแล้วเดือนนี้ และยอดรับชำระเดือนนี้ พร้อมตารางแยกตามตำบลและตามปีงบประมาณ ปุ่ม "ไป" ในตารางจะพาไปที่ตำบลนั้นทันที
- **ป้ายตำบล:** เดินไปที่ป้ายแล้วกด "ข้อมูลตำบล" จะเห็นสรุปของตำบลนั้น และรายชื่อกลุ่มเรียงจากด่วนที่สุด
- **บ้านแต่ละหลัง:** แสดงชื่อโครงการ ผู้เสนอ ที่อยู่ เลขที่สัญญา เงินกู้ สถานะหนี้ สถานะโครงการ และประวัติการติดตาม 5 ครั้งล่าสุด
- **ปุ่ม "ค้นหา":**
  - พิมพ์ค้นหาจากชื่อโครงการ ชื่อผู้เสนอ เลขที่สัญญา ชื่อบ้าน หรือหมู่
  - แตะปุ่มปี (ปี60 … ปี67) เลือกได้หลายปีพร้อมกัน
  - เลือกตำบล สถานะ หรือดูเฉพาะกลุ่มที่ยังไม่ได้เยี่ยม
  - ผลค้นหาบอกจำนวนกลุ่ม เงินกู้รวม และสัดส่วนสถานะ กด "นำทาง" ให้ลูกศรพาไป หรือ "ขี่มอไซค์ไป" ตำบลนั้น
  - **"แสดงบนแผนที่":** บ้านที่ตรงเงื่อนไขจะเด่น ที่เหลือจะจางลง มีแถบบอกเงื่อนไขอยู่ด้านล่าง กด ✕ เพื่อแสดงทุกบ้านอีกครั้ง
- **พัฒนาการอำเภอ** (NPC ที่สำนักงาน): แนะนำ 5 เควสที่ควรไปก่อน และแสดงอันดับพัฒนากร

## ไม่แสดงกลุ่มที่ปิดโครงการ
กลุ่มที่คอลัมน์ "สถานะโครงการ" เป็น **"ปิดโครงการ"** จะไม่ขึ้นในแผนที่เลย และไม่มีปุ่มให้เปิดกลับมา
- ไม่นับในหน้าค้นหา หน้าสรุป ตัวนับ "เยี่ยมเดือนนี้" และเควสแนะนำด้วย หน้าค้นหาและหน้าสรุปจะบอกว่าซ่อนไปกี่กลุ่ม
- กลุ่ม "เปิดโครงการ" และ "ระหว่างดำเนินคดี" ยังแสดงตามปกติ ส่วนกลุ่มที่ระหว่างดำเนินคดีจะมีป้ายสีน้ำตาลในหน้าข้อมูล
- ถ้ากลุ่มไหนกลับมาเปิดโครงการ ให้แก้ในชีต แล้วกด "ดึงข้อมูลใหม่" ในเกม

## ผลการลงพื้นที่
| ผล | EXP | นับว่าเยี่ยมแล้ว |
|---|---|---|
| รับชำระเงิน (ใส่จำนวนเงิน) | +50 | ✓ |
| นัดชำระ (ใส่วันนัด) | +30 | ✓ |
| แจ้งหนังสือทวงถาม | +20 | ✓ |
| เสนอปรับโครงสร้างหนี้ | +20 | ✓ |
| เยี่ยมติดตามกลุ่ม | +15 | ✓ |
| ไม่พบผู้กู้ | +10 | ✗ |

ทุกครั้งที่บันทึก เกมจะเพิ่ม 1 แถวในชีต **`บันทึกติดตาม`** (เวลา, พัฒนากร, เลขที่สัญญา, โครงการ, ตำบล, ผล, จำนวนเงิน, วันนัด, บันทึก)
**เกมไม่แก้คอลัมน์ "สถานะการชำระหนี้" ในชีตปีงบเดิม** ถ้าสถานะทางการเปลี่ยน ให้แก้ในชีตเองแล้วกด "ดึงข้อมูลใหม่" ในเกม

## สมุดบันทึกในเครื่อง (ปุ่ม "สมุด")
- ทุกครั้งที่บันทึกผล เกมจะเก็บ**สำเนาไว้ในโทรศัพท์**ด้วย เปิดดูย้อนหลังได้แม้ไม่มีสัญญาณ
- ดูได้ทีละเดือนหรือทั้งหมด มีสรุปจำนวนครั้ง จำนวนกลุ่มที่เยี่ยม ยอดรับชำระ และจำนวนนัดชำระ
- **ไม่มีสัญญาณตอนบันทึก:** รายการจะขึ้นว่า "รอส่ง" และมีตัวเลขสีแดงบนปุ่มสมุด เกมจะส่งเข้าชีตให้เองเมื่อกลับมามีสัญญาณหรือเปิดเกมครั้งถัดไป หรือกด "ส่งที่ค้าง" เองก็ได้
- **ดาวน์โหลด CSV:** เปิดใน Excel หรือ Google Sheets ได้ ภาษาไทยไม่เพี้ยน ถ้าเบราว์เซอร์ไม่ยอมดาวน์โหลด ให้ใช้ปุ่ม **คัดลอก** แล้ววางในโน้ตหรือไลน์ส่วนตัว
- ในสมุดจะไม่เก็บชื่อและที่อยู่ผู้กู้ เก็บเฉพาะชื่อโครงการ ตำบล หมู่ และเลขที่สัญญา
- ข้อควรระวัง: ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง สมุดในเครื่องจะหาย แต่ข้อมูลหลักยังอยู่ในชีต "บันทึกติดตาม" ยกเว้นรายการที่ยังขึ้นว่ารอส่ง

## ใช้กับอำเภออื่น
เกมไม่ได้ผูกกับ อ.โนนสัง ตำบล ชื่ออำเภอ และจังหวัด จะเปลี่ยนตามข้อมูลในชีตเอง ขอแค่ชีตเป็นแบบนี้:
- ชื่อแท็บขึ้นต้นด้วย **"ปี"** เช่น `ปี 66` หรือ `ปี67` แท็บอื่น (เช่น "บันทึกติดตาม" หรือ "สรุป") เกมจะไม่อ่าน
- คอลัมน์ **A–J เรียงเหมือนเดิม** (จังหวัด, อำเภอ/เขต, ปีงบประมาณ, เลขที่สัญญา, ชื่อโครงการ, ผู้เสนอ, สถานที่ดำเนินการ, จำนวนเงินกู้, สถานะการชำระหนี้, สถานะโครงการ) และแถวที่ 1 เป็นหัวตาราง
- ที่อยู่ควรมี **"ต." หรือ "ตำบล"** ถ้าแถวไหนไม่มี เกมจะลองเทียบกับชื่อตำบลที่เจอในแถวอื่นของอำเภอเดียวกัน ถ้ายังหาไม่ได้จะจัดไว้ใน "ไม่ระบุตำบล"
- ใส่หลายอำเภอในไฟล์เดียวได้ ตำบลจะขึ้นชื่อเป็น "ตำบล (อ.ชื่ออำเภอ)" เพื่อกันชื่อซ้ำ

**วิธีเปลี่ยนข้อมูล**
- **ใช้ไฟล์เดิม:** วางข้อมูลอำเภอใหม่ลงในแท็บ "ปี .." แล้วกด "ดึงข้อมูลใหม่" ในเกม หรือเปิดเกมใหม่ ไม่ต้อง Deploy ใหม่
- **ไฟล์ Google Sheet ใหม่ของอีกอำเภอ:** โค้ด Apps Script ผูกอยู่กับไฟล์ที่ติดตั้ง จึงต้องติดตั้งโค้ดในไฟล์นั้นอีกครั้งตามขั้นตอนด้านล่าง แล้วจะได้ URL เกมของอำเภอนั้นแยกต่างหาก (หรือใช้ ไฟล์ → ทำสำเนา จากไฟล์ที่ติดตั้งแล้ว โค้ดจะติดไปด้วย จากนั้นลบข้อมูลเก่า วางข้อมูลใหม่ แล้ว Deploy)
- เมื่อเปลี่ยนข้อมูลเป็นอำเภอใหม่ในไฟล์เดิม ประวัติใน "บันทึกติดตาม" ของอำเภอเดิมยังอยู่ ไม่หายไปไหน แต่จะไม่ขึ้นในแผนที่ เพราะเลขสัญญาไม่ตรงกัน

## ติดตั้ง (ประมาณ 5 นาที)
1. เปิดชีตข้อมูล แล้วไปที่ **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ให้ลบโค้ดเดิม วางโค้ดจาก `Code.gs` นี้ แล้วกดบันทึก
3. กด **＋ → HTML** ตั้งชื่อไฟล์ว่า `index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาทั้งหมดของ `index.html`
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ⚙ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **เฉพาะตัวฉันเอง**
5. กดอนุญาตสิทธิ์ แล้วเปิด URL เว็บแอปในมือถือ (ล็อกอิน Google บัญชีเดียวกัน) และกดเพิ่มลงหน้าจอโฮมได้

> แก้โค้ดภายหลังต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✎ → เวอร์ชันใหม่** โค้ดใหม่ถึงจะมีผล
> ถ้าเพิ่มชีตปีใหม่ (เช่น `ปี 68`) ที่มีคอลัมน์ A–J เหมือนเดิม เกมจะอ่านให้เองโดยไม่ต้องแก้โค้ด

### ถ้ามีพัฒนากรหลายคน
แชร์ชีตให้แต่ละคน (สิทธิ์ผู้แก้ไข) แล้ว deploy ใหม่โดยตั้ง "เรียกใช้ในฐานะ: **ผู้ใช้ที่เข้าถึงเว็บแอป**" และ "ผู้มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google**"
ระบบจะให้เฉพาะคนที่มีสิทธิ์ในชีตเปิดข้อมูลได้เท่านั้น

## ความเป็นส่วนตัวและกฎหมาย
- ข้อมูลผู้กู้อยู่ใน Google Sheet ของคุณเท่านั้น ไม่มีชื่อจริงในโค้ดหรือในลิงก์ทดลอง
- ห้ามแคปหน้าจอที่มีชื่อหรือที่อยู่ผู้กู้ส่งต่อในกลุ่มแชต
- พ.ร.บ.การทวงถามหนี้ พ.ศ. 2558: ห้ามประจาน ห้ามบอกเรื่องหนี้กับบุคคลอื่น และติดต่อได้เฉพาะ 08:00–20:00 น. (วันหยุดราชการ 08:00–18:00 น.)

## ตัวละครและยศ
ผู้เล่นคือ **พัฒนากร** ใส่เครื่องแบบสีกากี หมวกแก๊ป และถือแฟ้มเอกสาร ยศจะขึ้นตามเลเวล:
พัฒนากรฝึกหัด (Lv1–2) → ปฏิบัติการ (Lv3–4) → ชำนาญการ (Lv5–6) → ชำนาญการพิเศษ (Lv7–8) → ยอดพัฒนากรประจำอำเภอ (Lv9+)
