# พัฒนากรออกเควส

เกม RPG มุมมองจากด้านบน สำหรับ**พัฒนากร** ใช้ลงพื้นที่ติดตามหนี้กองทุนพัฒนาบทบาทสตรี อ.โนนสัง
ข้อมูลอ่านจากชีต "สถานะลูกหนี้ตามสัญญา รวม" (ชีต `ปี 60` … `ปี 67`) โดยตรง

- `index.html` คือตัวเกม (ถ้าเปิดนอก Apps Script จะเป็นโหมดทดลองที่ใช้ข้อมูลสมมติ)
- `Code.gs` คือตัวเชื่อม Google Sheet

## แผนที่อ่านข้อมูลอย่างไร
| ในชีต | ในเกม |
|---|---|
| แต่ละแถว (1 สัญญา/กลุ่ม) | บ้าน 1 หลัง มีชื่อโครงการ หมู่ และปีงบเขียนใต้บ้าน |
| ตำบลใน "สถานที่ดำเนินการ" | หมู่บ้านกลุ่มหนึ่งบนแผนที่ มีป้ายตำบลอยู่ตรงกลาง |
| สถานะการชำระหนี้ | สีของเครื่องหมายบนหลังคา และความด่วนของเควส |

| สถานะ | สี | ลำดับความด่วน |
|---|---|---|
| ทวงถามครั้งที่ 2 | แดง ! | 1 |
| ทวงถามครั้งที่ 1 | ส้ม ! | 2 |
| ค้างชำระ | เหลืองเข้ม ! | 3 |
| ปรับโครงสร้าง ตามประกาศรอบที่ … | ม่วง ! | 4 |
| รอชำระ | ฟ้า ! | 5 |
| ชำระครบตามสัญญา | เขียว ★ (ไม่เป็นเควส) | – |

บ้านที่เยี่ยมแล้วในเดือนนี้จะเปลี่ยนเป็น ✓ และจะกลับมาเป็นเควสใหม่ในเดือนถัดไป

## ดูข้อมูลแต่ละกลุ่ม
- **ปุ่ม "สรุป":** ภาพรวมทั้งอำเภอ ได้แก่ จำนวนสัญญา เงินกู้รวม จำนวนที่ค้างหรือถูกทวงถาม จำนวนที่เยี่ยมแล้วเดือนนี้ และยอดรับชำระเดือนนี้ พร้อมตารางแยกตามตำบลและตามปีงบประมาณ ปุ่ม "ไป" ในตารางจะพาไปที่ตำบลนั้นทันที
- **ป้ายตำบล:** เดินไปที่ป้ายแล้วกด "ข้อมูลตำบล" จะเห็นสรุปของตำบลนั้น และรายชื่อกลุ่มเรียงจากด่วนที่สุด
- **บ้านแต่ละหลัง:** แสดงชื่อโครงการ ผู้เสนอ ที่อยู่ เลขที่สัญญา เงินกู้ สถานะหนี้ สถานะโครงการ และประวัติการติดตาม 5 ครั้งล่าสุด
- **ปุ่ม "เควส":** กรองตามตำบลและสถานะ หรือดูเฉพาะกลุ่มที่ยังไม่ได้เยี่ยมเดือนนี้ แล้วกด "นำทาง" ให้ลูกศรพาไป
- **พัฒนาการอำเภอ** (NPC ที่สำนักงาน): แนะนำ 5 เควสที่ควรไปก่อน และแสดงอันดับพัฒนากร

## ผลการลงพื้นที่
| ผล | EXP | นับว่าเยี่ยมแล้ว |
|---|---|---|
| รับชำระเงิน (ใส่จำนวนเงิน) | +50 | ✓ |
| นัดชำระ (ใส่วันนัด) | +30 | ✓ |
| แจ้งหนังสือทวงถาม | +20 | ✓ |
| เสนอปรับโครงสร้างหนี้ | +20 | ✓ |
| เยี่ยมติดตามกลุ่ม | +15 | ✓ |
| ไม่พบผู้กู้ | +10 | ✗ |

ทุกครั้งที่บันทึก เกมจะเพิ่ม 1 แถวในชีต **`บันทึกติดตาม`** (เวลา, พัฒนากร, เลขที่สัญญา, โครงการ, ตำบล, ผล, จำนวนเงิน, วันนัด, บันทึก)
**เกมไม่แก้คอลัมน์ "สถานะการชำระหนี้" ในชีตปีงบเดิม** ถ้าสถานะทางการเปลี่ยน ให้แก้ในชีตเองแล้วกด "ดึงข้อมูลใหม่" ในเกม

## ติดตั้ง (ประมาณ 5 นาที)
1. เปิดชีตข้อมูล แล้วไปที่ **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ให้ลบโค้ดเดิม วางโค้ดจาก `Code.gs` นี้ แล้วกดบันทึก
3. กด **＋ → HTML** ตั้งชื่อไฟล์ว่า `index` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาทั้งหมดของ `index.html`
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ⚙ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **เฉพาะตัวฉันเอง**
5. กดอนุญาตสิทธิ์ แล้วเปิด URL เว็บแอปในมือถือ (ล็อกอิน Google บัญชีเดียวกัน) และกดเพิ่มลงหน้าจอโฮมได้

> แก้โค้ดภายหลังต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✎ → เวอร์ชันใหม่** โค้ดใหม่ถึงจะมีผล
> ถ้าเพิ่มชีตปีใหม่ (เช่น `ปี 68`) ที่มีคอลัมน์ A–J เหมือนเดิม เกมจะอ่านให้เองโดยไม่ต้องแก้โค้ด

### ถ้ามีพัฒนากรหลายคน
แชร์ชีตให้แต่ละคน (สิทธิ์ผู้แก้ไข) แล้ว deploy ใหม่โดยตั้ง "เรียกใช้ในฐานะ: **ผู้ใช้ที่เข้าถึงเว็บแอป**" และ "ผู้มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google**"
ระบบจะให้เฉพาะคนที่มีสิทธิ์ในชีตเปิดข้อมูลได้เท่านั้น

## ความเป็นส่วนตัวและกฎหมาย
- ข้อมูลผู้กู้อยู่ใน Google Sheet ของคุณเท่านั้น ไม่มีชื่อจริงในโค้ดหรือในลิงก์ทดลอง
- ห้ามแคปหน้าจอที่มีชื่อหรือที่อยู่ผู้กู้ส่งต่อในกลุ่มแชต
- พ.ร.บ.การทวงถามหนี้ พ.ศ. 2558: ห้ามประจาน ห้ามบอกเรื่องหนี้กับบุคคลอื่น และติดต่อได้เฉพาะ 08:00–20:00 น. (วันหยุดราชการ 08:00–18:00 น.)

## ตัวละครและยศ
ผู้เล่นคือ **พัฒนากร** ใส่เครื่องแบบสีกากี หมวกแก๊ป และถือแฟ้มเอกสาร ยศจะขึ้นตามเลเวล:
พัฒนากรฝึกหัด (Lv1–2) → ปฏิบัติการ (Lv3–4) → ชำนาญการ (Lv5–6) → ชำนาญการพิเศษ (Lv7–8) → ยอดพัฒนากรประจำอำเภอ (Lv9+)
