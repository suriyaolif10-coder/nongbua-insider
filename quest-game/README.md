# เควสหมู่บ้าน

เกม RPG แบบมองจากด้านบน สำหรับ**พัฒนากร** (เจ้าหน้าที่ผู้มีหน้าที่ติดตามหนี้กองทุนกลุ่มสตรี) ใช้ลงพื้นที่ติดตามหนี้แบบสุภาพ
ข้อมูลเควสดึงจาก Google Sheet และผลการติดตามถูกบันทึกกลับลงชีตอัตโนมัติ

- `index.html` คือตัวเกม (ไฟล์เดียว เปิดบนมือถือหรือคอมได้)
- `Code.gs` คือตัวเชื่อม Google Sheet (Google Apps Script)

## วิธีเล่น
- จอยซ้ายล่าง (หรือปุ่ม WASD/ลูกศร) ใช้เดิน ปุ่มแดงขวาล่าง (หรือ Space/E) ใช้ทำเควส
- บ้านที่มี **!** สีเหลืองคือเควสที่ยังค้าง ส่วน **✓** สีเขียวคือปิดแล้ว
- ปุ่ม "เควส" เปิดรายการทั้งหมด กด "นำทาง" แล้วจะมีลูกศรสีฟ้าพาไป
- คุยกับประธานกลุ่มที่ลานกลางเพื่อดูยอดทีมและอันดับ EXP

| ผลการติดตาม | EXP | ปิดเควส |
|---|---|---|
| รับชำระแล้ว | +50 | ✓ |
| นัดผ่อนชำระ | +30 | ✓ |
| ส่งต่อคณะกรรมการ (ลำบากจริง) | +20 | ✓ |
| ไม่พบเจ้าของบ้าน | +10 | ยังค้าง |

## เชื่อมกับ Google Sheet
1. สร้าง Google Sheet ใหม่ แล้วไปที่ **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `Code.gs` แล้วกดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (ครั้งแรกจะให้อนุญาตสิทธิ์) จะได้ชีต `Quests`, `Log`, `Config`
4. ในชีต `Config` เปลี่ยน `TEAM_PIN` เป็นรหัสทีมของคุณ และตั้ง `MONTHLY_TARGET`
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
6. คัดลอก URL ของเว็บแอป ไปใส่ใน `index.html` ที่บรรทัด `API_URL: ''`
7. นำ `index.html` ขึ้นเว็บ (เช่น GitHub Pages) หรือส่งไฟล์ให้ทีมงานเปิดในมือถือ

> ถ้าแก้ `Code.gs` ภายหลัง ต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** โค้ดใหม่ถึงจะมีผล

### ชีต `Quests` (ประธานเพิ่ม/แก้แถวเอง)
| คอลัมน์ | ความหมาย |
|---|---|
| quest_id | รหัสเควส ห้ามซ้ำ เช่น Q001 |
| house_code | รหัสบ้าน/รหัสสมาชิก ที่แสดงบนแผนที่ (**ไม่ควรใช้ชื่อจริง**) |
| zone | หมู่/โซน |
| task | สิ่งที่ต้องทำ |
| owed | ยอดงวดค้าง (บาท) แสดงเฉพาะในหน้าต่างเควส |
| status | `open` หรือ `done` (เปิดเควสใหม่ได้โดยเปลี่ยนกลับเป็น `open`) |
| last_note, last_visit | เกมจะเขียนให้เอง |
| map_x, map_y | (ไม่บังคับ) ตำแหน่งบนแผนที่ 0–100 ถ้าเว้นว่าง เกมจะจัดวางเอง |

ชีต `Log` จะเก็บทุกการส่งผล (เวลา, ทีมงาน, ผล, ยอดเงิน, บันทึก, EXP) ใช้ทำรายงานต่อได้

## ความเป็นส่วนตัวและกฎหมาย
- ใช้ **รหัสบ้าน/รหัสสมาชิก** แทนชื่อจริงในชีต Quests โดยเก็บตารางจับคู่ชื่อไว้ในไฟล์อื่นที่เฉพาะกรรมการเปิดได้
- รหัสทีมเป็นการป้องกันระดับพื้นฐานเท่านั้น ห้ามแชร์ลิงก์และรหัสในกลุ่มสาธารณะ และควรเปลี่ยนรหัสเมื่อมีคนออกจากทีม
- พ.ร.บ.การทวงถามหนี้ พ.ศ. 2558: ห้ามประจาน ห้ามบอกเรื่องหนี้กับบุคคลอื่น และติดต่อได้เฉพาะ 08:00–20:00 น. (วันหยุดราชการ 08:00–18:00 น.)

## ตัวละครและยศ
ผู้เล่นคือ **พัฒนากร** ใส่เครื่องแบบสีกากี หมวกแก๊ป และถือแฟ้มเอกสาร ยศจะขึ้นตามเลเวล:
พัฒนากรฝึกหัด (Lv1–2) → ปฏิบัติการ (Lv3–4) → ชำนาญการ (Lv5–6) → ชำนาญการพิเศษ (Lv7–8) → ยอดพัฒนากรประจำอำเภอ (Lv9+)
